## Getting Started

### System Requirements

**Minimum Requirements**:
- Modern web browser (Chrome, Firefox, Safari, Edge)
- Internet connection
- Audio output (speakers or headphones)
- JavaScript enabled

**Recommended**:
- Chrome browser (for best audio experience)
- Headphones (for immersive audio)
- Large screen (for detailed visualizations)

### First Visit

1. **Open the Application**
   - Visit the website URL
   - Wait for content to load (usually 2-3 seconds)

2. **Audio Permissions**
   - Click anywhere on the page to enable audio
   - Most browsers require user interaction before playing audio

3. **Explore**
   - Scroll through the homepage
   - Open the navigation menu (hamburger icon)
   - Select a pollutant to explore

## Navigation Menu

### Opening the Menu

**Desktop & Mobile**:
- Click the hamburger icon (three horizontal lines) in the top right corner
- Menu slides in from right side

**Keyboard**:
- Tab to hamburger button
- Press Enter or Space

### Menu Structure

The menu contains four main categories:

1. **Agriculture Waste**
   - Pesticides, herbicides, fertilizers
   - Organic compounds
   - Nutrient pollution

2. **Heavy Metal Waste**
   - Lead, mercury, cadmium
   - Arsenic, chromium
   - Industrial pollutants

3. **Radioactive Waste**
   - Uranium, plutonium
   - Cesium, strontium
   - Nuclear byproducts

4. **Sewage Waste**
   - Bacteria (E. coli, etc.)
   - Viruses
   - Organic matter

### Navigating Categories

#### Expanding a Category

1. **Click Category Name** or **Arrow Button**
   - Category expands to show visual map
   - All other categories collapse
   - Menu scrolls to show expanded content

2. **Explore Visual Map**
   - Detailed SVG illustration
   - Clickable pollutant names
   - Visual groupings

3. **Select a Pollutant**
   - Click on any pollutant name
   - Navigate to detailed pollutant page

#### Collapsing a Category

1. **Click X Button** on expanded category
   - Category collapses
   - Menu returns to compact view
   - Scrolls back to top

### Menu Features

**Home Button**:
- Returns to homepage
- Located at top of menu

**Close Button**:
- Closes entire menu
- X icon in top right
- Or press Escape key

**Auto-Scaling**:
- Menu automatically scales to fit your screen
- All four categories always visible (when not expanded)

## Audio Features

### Sound Toggle

**Location**: Top right corner (both homepage and pollutant pages)

**Function**:
- Toggle audio on/off
- Icon changes based on state:
  - Sound waves: Audio ON
  - Speaker with X: Audio OFF

**States**:
- **Active (White icon)**: Audio is playing
- **Inactive (Muted)**: Audio is off
- State persists across pages

### Ambient Sound

**Pad 999**:
- Background soundscape
- Loops continuously
- Represents overall water environment
- Can be toggled with sound button

### Pollutant Sounds

**Individual Audio**:
- Each pollutant has unique sound
- Triggered by:
  - Hovering over interactive elements
  - Visiting pollutant page
  - Manual playback controls

**Features**:
- Smooth fade-in when starting
- Smooth fade-out when stopping
- Seamless looping
- No audio clicks or pops

### Audio Controls

**Mute/Unmute**:
- Global mute affects all sounds
- Preference saved to browser
- Persists between sessions

**Volume**:
- Controlled by system volume
- Individual sounds have preset volumes

## FAQ

### General Questions

**Q: What is sonification?**
A: The process of converting data into sound. In this project, each pollutant's characteristics are translated into a unique audio signature.

**Q: Why can't I hear any audio?**
A: 
1. Click anywhere on the page first (browser requirement)
2. Check sound toggle is not muted
3. Verify system volume is up
4. Check browser audio settings

**Q: How do I navigate back?**
A: Use the back button in your browser, or click the back arrow on pollutant pages, or open the menu and click "Home".

**Q: Can I use this on my phone?**
A: Yes! The entire site is optimized for mobile devices.

**Q: How do I share a specific pollutant?**
A: Copy the URL from your browser, or use the share buttons on pollutant pages.

### Technical Questions

**Q: Which browsers are supported?**
A: Chrome (recommended), Firefox, Safari, and Edge. All modern browsers are supported.

**Q: Why is the audio lagging?**
A: 
1. Close other browser tabs
2. Restart browser
3. Try Chrome for best performance
4. Check internet connection

**Q: How can I download the audio?**
A: The audio files are embedded and not directly downloadable. Contact the team for access.

**Q: Is there an offline version?**
A: Not currently. The app requires internet for Google Sheets data and audio files.

### Content Questions

**Q: How many pollutants are documented?**
A: The database contains 50+ pollutants across 4 main categories.

**Q: Are the plant remediation capacities accurate?**
A: Yes, all data is based on scientific research and case studies.

**Q: Can I suggest a new pollutant to add?**
A: Yes! Contact the development team or open a GitHub issue.

**Q: Where does the data come from?**
A: Data is sourced from scientific literature, environmental databases, and case studies.

## Accessibility

### Screen Readers

**Support**:
- All images have alt text
- ARIA labels on interactive elements
- Semantic HTML structure
- Keyboard navigation

**Screen Reader Tips**:
- Navigate by headings
- Use landmarks (nav, main, footer)
- Interactive elements are properly labeled

### Keyboard Navigation

**Full keyboard support**:
- `Tab`: Move forward through elements
- `Shift + Tab`: Move backward
- `Enter` or `Space`: Activate element
- `Escape`: Close menus/dialogs

### Visual Accessibility

**Features**:
- High contrast text
- Large, readable fonts
- Clear visual hierarchy
- Color is not the only indicator

**Adjustments**:
- Browser zoom supported
- Text scales properly
- Layout remains usable

### Motor Accessibility

**Features**:
- Large click/tap targets
- No time-limited interactions
- No rapid movements required
- Forgiving click areas

## Troubleshooting

### Common Issues

**Issue: Page won't load**
- Check internet connection
- Try refreshing page (Ctrl/Cmd + R)
- Clear browser cache
- Try different browser

**Issue: Audio not working**
- Click on page first
- Check mute button
- Verify system volume
- Try different browser

**Issue: Images not loading**
- Check internet connection
- Wait longer for high-res images
- Try refreshing page

**Issue: Menu won't open**
- Check if JavaScript is enabled
- Try different browser
- Clear cache and cookies

**Issue: Mobile site not responsive**
- Try rotating device
- Check browser zoom level
- Try different mobile browser
